# Ядро для интернет-магазина
Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```
Установите зависимости, используя менеджер пакетов 'poetry':
```
poetry install
```
## Использование:

Откройте в вашем PyCharm.
Включает в себя следующий функционал:
1. Класс Product со свойствами:
название (name), описание (description), цена (price),
количество в наличии (quantity)
2. Класс Category со свойствами:
название (name), описание (description),
список товаров категории (products).Также есть два атрибута класса:
количество категорий (category_count) и количество товаров (product_count).


## Тестирование
Код покрыт тестами. Для ознакомления зайдите в htmlcov -> index.html и оттуда перейдите в браузер -
вы увидете процент покрытия кода тестами. Также это можно сделать командой
```
poetry run pytest --cov
```
Все тесты расположены в пакете tests.
