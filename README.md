# Ядро для интернет-магазина
Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```
Установите зависимости, используя менеджер пакетов 'poetry':
```
poetry install
```
## Использование:

Откройте в вашем PyCharm.
Включает в себя следующий функционал:
1. Класс Product со свойствами:
название (name), описание (description), цена (price),
количество в наличии (quantity). 

Для класса Product реализовано строковое отображение в следующем виде:
"Название продукта, 80 руб. Остаток: 15 шт."

Для удобства работы с продуктами реализована возможность их складывать. 
Логика сложения работает так, что в итоге у вас получается полная стоимость всех товаров на складе.

Для класса Product создан класс-метод new_product, который принимает на вход 
параметры товара в словаре и возвращет созданный объект класса Product.
2. Класс Category со свойствами:
название (name), описание (description),
список товаров категории (products).Также есть два атрибута класса:
количество категорий (category_count) и количество товаров (product_count).

Для класса Category реализовано строковое отображение в следующем виде:
"Название категории, количество продуктов: 200 шт."

Для класса Category реализовано добавление продукта в категорию.
3. Класс Smartphone со свойствами:
название (name), описание (description), цена (price),
количество в наличии (quantity),производительность (efficiency),
модель (model), объем встроенной памяти (memory), цвет (color).
Класс-наследник от класса Product.
4. Класс LawnGrass со свойствами:
название (name), описание (description), цена (price),
количество в наличии (quantity), страна-производитель (country),
срок прорастания (germination_period), цвет (color).
Класс-наследник от класса Product. 

## Тестирование
Код покрыт тестами. Для ознакомления зайдите в htmlcov -> index.html и оттуда перейдите в браузер -
вы увидете процент покрытия кода тестами. Также это можно сделать командой
```
poetry run pytest --cov
```
Все тесты расположены в пакете tests.
